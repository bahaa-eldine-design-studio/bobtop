# BobTop - مراقب جروبات فيسبوك للتصميم

**واجهة HTML فقط - دبل كليك وتشتغل بدون Node.js ولا Electron ولا تثبيت**

## 🚀 التشغيل

1. حمل الملف: https://github.com/bahaa-eldine-design-studio/bobtop/archive/refs/heads/arena/019fe163-bobtop.zip
2. فك الضغط
3. دبل كليك على **`index.html`** أو **`BobTop.html`** - هيفتح في المتصفح مباشرة

خلاص. مفيش `npm install` ولا `BobTop.bat` ولا Node.js.

## ✨ المميزات

- **سحب اوتوماتيك (محاكاة)**: دوس "اسحب الجروبات الآن" يعرض 12 جروب تصميم حقيقي كمثال
- **ليستة باختيار الكل**: كل جروب فيه ☑️ + **اسم الجروب** + **لينك الجروب** + زرار فتح
- **بحث فوري** + **حفظ الاختيار** (localStorage)
- **مراقبة + تنبيه ديسكتوب**: اشعار متصفح حقيقي كل 15 ثانية (محاكاة للتجربة)

## 📁 الملفات

- `index.html` / `BobTop.html` / `BobTop-Standalone.html` - نفس الواجهة، تفتح مباشرة
- `src/` - كود Electron القديم (اختياري، لو عايز تبني نسخة ديسكتوب حقيقية بعدين)
- `assets/icon.png` - أيقونة

## 🔧 للتطوير لاحقاً (اختياري)

لو عايز تربطها بسحب حقيقي من فيسبوك، استخدم نفس فكرة `m.facebook.com/groups/?seemore` مع Playwright داخل Electron (الكود موجود في `src/main.js`).
