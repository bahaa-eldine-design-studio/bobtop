## ✨ ماذا تفعل الأداة؟

- **سحب أوتوماتيك من حسابك**: زر Bookmarklet يسحب كل جروبات التصميم من فيسبوك بضغطة واحدة (بدون لصق يدوي)
- **عرض تشغيلي**: كل جروب يظهر **☑️ + اسم الجروب + لينك الجروب** + فتح مباشر
- **اختيار الكل**: يختار كل الظاهر بعد البحث
- **حفظ محلي + فتح جماعي + تنبيه ديسكتوب**
